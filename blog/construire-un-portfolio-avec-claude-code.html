Construire un portfolio avec Claude Code

15 août 2026

Ce portfolio est entièrement construit avec Claude Code, section par section : la structure HTML, les styles CSS, les animations et même le toggle dark/light mode.

Mon rôle a été de décrire précisément ce que je voulais - le contenu, le comportement, les contraintes visuelles - et de valider chaque étape avant de passer à la suivante.

Cette approche m'a appris qu'un bon product builder n'a pas besoin de tout écrire lui-même, mais doit savoir exactement ce qu'il veut et pourquoi.
